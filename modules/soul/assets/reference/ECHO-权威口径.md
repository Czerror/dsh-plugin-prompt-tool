# ECHO：概念与本插件映射

ECHO 管「我是谁、我记得什么」，重点是能否凭来源找回并核对事实。这里统一说明 ECHO 内部分层；整体功能六层另见 [layers.md](../layers.md)，两种分类不混用。实际操作以 [tools.md](../tools.md) 与 [ledger.md](../ledger.md) 为准。

## L0–L5

| 层 | 概念 | 本插件中的对应与边界 |
|---|---|---|
| L0 | 时钟 + 心跳 | 用 `soul_state action: status` 查看当前时钟、会话状态与来源；标记时间不等于实际活动时间。本插件不由此承诺心跳调度或定时重建。 |
| L1 | 自我 + 热记忆 | 有效 SELF 承载身份、硬线、门与已生效约定，运行事实由宿主提供；新学习须区分候选、采纳与失效。概念不代表已安装独立热记忆服务。 |
| L2 | 工作台 | 当前对话上下文，可以按宿主策略压缩或裁剪；派生产物要留下可核对的来源入口。 |
| L3 | 一手层 | 账本、已授权会话及知识来源中的原始内容。各来源遵守自身写入、保留、删除和撤权规则；Soul 账本只追加，不代表其他来源一律不可删除。 |
| L4 | 索引 + 图记忆 | 索引、摘要等可重建派生信息，不取代原文。撤权、来源不可用或版本失效时停止将相关派生信息作为有效依据；不表示本插件另装图记忆服务。 |
| L5 | 检索 + 门牌 | 用 `module_search` 查已授权资料，再用返回的 `reference` 调 `module_open` 核对原文；引用会重新校验授权与版本，本身不是访问凭据。 |

压缩工作台不能代替删除来源的授权流程；保留了索引也不表示仍有权读取原文。持续记忆默认未接入，须由用户选择知识库并授权；升级、装配或已有引用均不替代授权。用户撤权、撤回学习或遗忘后，不继续把失效内容当作有效记忆。

## 必要原则

- **原文优先，摘要只是索引。** 摘要与原文冲突时回到原文核对；摘要、推断与运行事实要能区分。
- **压缩与裁剪产物必须能回指来源。** 使用真实返回的引用；拿不到精确位置时明确未知并给可用检索入口，不猜坐标，不把回取失败说成已核实。
- **同一事实只有一个权威来源。** 事件、承诺和未结留账本索引，较长材料与决定依据按授权落入知识库，其余位置保留引用。状态变化走现有流程，不重复记账。
- **身份不绑定可替换工具。** 能力可以替换，身份、硬线和授权边界不能借同步上游配置一并替换。
- **SELF 保持短而有效。** 核心身份与锁定偏好不能因预算静默丢失；动态事实由宿主生成，未知不冒充零。以实际投递和预算状态判断是否生效，不把文件存在或记录成功等同于学习采纳。

## 自检看什么

哨兵是观测面，不是第七层；观测本身不产生记忆，也不决定学习采纳。

用 `soul_state action: check` 只读核对文件、SELF 实际投递、索引与运行观测，用 `status` 区分未接入、不可用、候选、采纳及失效等状态。每一项都应说明：管理什么资源、唯一权威在哪里、坏了怎样发现、通过什么接口核对。

- 引用能否在当前授权与版本下回到原文，还是只剩摘要或失效指针？
- SELF 是否实际投递，身份和动态事实是否可核对，预算问题是否可见？
- 账本与知识来源是否各有明确归属，未结状态是否来自同一投影？
- 检查从哪里取证，有哪些未检查或无法观测的部分？

**未检查不等于通过，找不到证据不等于事情没有发生。** 缺失、不可用、失败与成功分别说明，不把索引条数或文件齐全当作完整闭环的证据。
