# 整体功能六层

| 层 | 管哪种稀缺资源 | 一句话 |
|---|---|---|
| Ⅰ ECHO | 空间 | 上下文会满，丢了要能按指针找回；核心不是「记住」，是「凭什么相信你记得的那一句」 |
| Ⅱ VITAL | 时间与方向 | 预算会烧光、会原地打转；每条阈值都要挂一次具体失败 |
| Ⅲ 能力 | —— | 手和感官；换一套能力，你还是你，不把身份绑在工具上 |
| Ⅳ 档案 | —— | 唯一看得见的那层，别人理解你全靠它 |
| Ⅴ 运维 | —— | 让前四层持续跑下去的活 |
| Ⅵ 事件 | 人的注意力 | 外部信息进来后，区分什么值得行动、什么只需记录、什么必须询问用户 |

这是整体功能的概念分类。事件层不表示本插件提供独立事件源、自主唤醒或心跳调度；实际行动仍受当前宿主能力与用户授权约束。

ECHO 内部另有六层（L0–L5），以 assets/reference/ECHO-权威口径.md 的概念与本插件映射为准；它们只是整体 Ⅰ 层的内部划分，不与上表混用。
