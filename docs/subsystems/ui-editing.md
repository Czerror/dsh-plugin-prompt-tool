# 客户端读取、草稿与保存

## 首屏读取与更新

    打开任一原生工作台入口
      -> 激活独立 WorkspaceStoreOwner 并按需 store.load()
      -> bridgeCall("bootstrap") 聚合 descriptor、meta、变量和 promptConfigs
      -> fieldsFromView() 合并 value/base 与 moduleParams
      -> useRuleEditor() 去重读取 /rules，建立正文、settings、variables 的 revisions 基线
      -> /models 按需加载并缓存模型目录
      -> page selector 订阅 fields 引用

bootstrap 是首屏聚合请求，不因筛选或输入字符增加 bridge 请求。模型目录保持惰性加载；筛选、状态筛选和搜索在客户端完成。

`bootstrap` 对显式模块目录只解析一次，身份、参数、能力、变量及配置投影来自同一份定义。没有模块主语时的字段缺席规则见 [Bridge 主语](ui-bridge.md#模块主语策略)。

同一预设的后台刷新同时保护请求开始前已有的未保存提示词配置与模板变量草稿，以及请求期间新增的编辑。保存后同步元数据时，已确认写入的提示词定义不被暂时为空的生成快照覆盖。未填写名称的变量行只在写入载荷中清理，本地编辑行保留；预设身份切换仍按原保存与上下文边界处理。

页面通过 `usePromptToolFields` 订阅窄切片。值未变时 `useSyncExternalStore` 复用快照引用；只在有实测收益时保留 memo 和稳定回调。`use-prompt-tool-store.ts` 组合 ConfigForms 镜像、Bridge、字段、队列与动作。新增卡片从 [store-ports.ts](../../src/client/data/store-ports.ts) 选择实际依赖的端口，并通过交叉类型声明，测试桩沿同一端口。

## 草稿与编辑所有权

| 状态 | Owner | 生命周期/规则 |
|---|---|---|
| filter、search、列表展开、页滚动 | workspace-browse-state | 工作台实例期，配置视图按页面/预设区分；异步资源就绪后一次恢复滚动 |
| 两级变量草稿 | module-variables + 现有变量编辑卡 | 按模块ID+scope隔离；同名覆盖来源来自 effective 快照，迟到响应只回原草稿 |
| 模块参数与全局参数 | param-editor | 工作台内共享 ParamsPort；条目、有效基线、已存键、读取去重与保存应答归同一 owner，原始数字/JSON 输入仍在 workspace-drafts |
| 人设动作 | RuleSteps + ModulePersonaCard + rule-drafts | 正文、受众与三态字段归属普通规则；复用规则身份、CAS、保存与发布重试 |
| 工具、规则动作、原始 JSON/数字草稿 | store.editorDrafts / workspace-drafts | 按预设和字段身份保留；未存草稿或保存中在覆盖导入时按模块拦截（`poolDirty`）；改名迁移、删除清理对应字段 |
| 模块规则与条件/动作字段草稿 | rule-drafts + use-rule-editor | 每模块单一 owner、读取去重、稳定编辑 key；改名/删除保留 previousId；CAS 失败和请求期间的新编辑不丢失 |
| 指令文件正文草稿 | instruction-drafts | 与预设保存队列分离；按指令上下文（`contextId`）隔离，旧上下文迟到响应不覆盖当前视图 |
| 指令文件卡壳与视图 | instruction-editor 投影（壳 + 池 + 策略） | 壳只来自 `/bootstrap` 的指令卡会话段（descriptor 不提供该输入，壳来源过滤在 `instructionShellsFrom`）；`fields.instructionCards` 永远是三者投影的结果，不是编辑源 |
| 导入预览与提交阶段 | use-import-preview-flow | 每次 `run()` 独立生命周期；卸载结束等待、不悬挂 Promise |
| 创建意图、菜单、删除/导入确认、拖拽 | 对应 feature | 仍随页面卸载失效；不恢复或重放危险操作 |
| 模板创建目标与发布结果 | template-rule-writer + rule-drafts | 目标意图归视图，显式 moduleId 写入、声明与结果接纳归数据侧；不依赖 owner/readback。共享草稿保存完整成功响应和发布状态，离页只抑制提示／展开，不丢已提交事实；未启用目标的状态仍仅存工作台会话，启用后沿既有 refreshOnly 重试 |
| 保存队列、revision、草稿版本 | save-queue + store | 独立数据 owner 生命周期，视图卸载不取消已发起保存 |
| 大文本和导入原文件 | 文件通道/bridge | 不进入 settings descriptor |

模块修改由数据侧 `module-actions` 统一组织创建、克隆、复制、删除、启停、名称写入与后续事实刷新，复用工作台保存队列；读取名称和打开目录不触发重载。页面只负责输入、确认与反馈，不再手写操作后的全局刷新。返回结果区分写入拒绝与已提交后的 `refreshError`；后者只重载事实，不重放修改。既有导入预览／确认保留在导入流程，提交后的目录刷新复用同一入口。

操作后的刷新使用 `/meta` 更新模块事实，不以 `/bootstrap` 覆盖总闸、指令或全局参数草稿。共享序号保证迟到的旧 bootstrap 不回退较新的模块目录。干净的模块参数缓存重新读取，已删除声明节恢复空基线；脏值和原始输入保留，后台参数响应只更新读取期间未编辑的字段。规则缓存只标记需要重读，entries/fields 与冲突状态不清除。

规则操作在入口校验当前编辑资格，用户已发起并进入队列的显式目标保存不因切页取消。已发起的读取、写入及发布响应按共享草稿序号接纳，视图卸载不丢结果，也不让新页面卡在过期的 busy 状态。发布重试同时接纳最新正文与版本：无本地编辑时更新基线，有本地编辑且远端变化时保留输入并进入冲突；不以旧整卡覆盖新输入。模板创建的声明事实、完整响应与发布状态归共享规则草稿，不另建视图级声明缓存；“本次新建”仍是每次选择意图，不跨失败或取消传播到随后选择的既有模块。

业务草稿不写 localStorage，不靠常驻四页保留。工具与规则动作只确认提交快照，保存途中继续编辑仍待存；同预设重挂共享在途状态。干净重挂重新读取远端事实，脏草稿优先保留。

`store.persistBeforeLeave()` 处理全局开关及指令文件；规则由各模块的编辑器保存。

## 保存保护

全局部署设置、模块操作及指令正文各有自己的写入通道。公共参数、规则、能力创建／移除与模块修改共享模块保存队列。切换模块先处理未保存草稿并等待队列；在途应答只能更新原目标。

模块参数进入共享队列后，在任务开始执行时捕获提交快照；全局参数在入队前捕获。模块参数的跨域刷新资格在入队前捕获，排队期间的新编辑也能阻止整轮刷新。成功只确认已提交快照，在途新输入保持 dirty。全局草稿版本未变、其他通道无待存草稿且对应草稿仍等于请求快照时，队列内才执行静默读取。

各编辑 owner 在读取时保存版本，写入时提交期望版本。规则使用 `rules[id]` 与 `settings`，变量内容按 scope、模块开关按 `settings`，指令逐文件使用 `revision`，配置排序使用整表版本。工具编辑的是整组工具，保留发布态和 `refreshOnly` 恢复。读取、写入和发布应答按 `resource-track.ts` 的最新请求序号接纳；迟到应答既不写草稿，也不清理当前请求的忙态。

普通保存收到 `persisted:true` 即确认提交快照，界面可以继续编辑。规则顶栏和列表从 `publicationPending` 与可选的 `publicationError` 读取已保存版本的发布进度及失败原因。新草稿保存被拒时，两处同时显示这次拒绝原因与上个版本的发布状态。其他使用 `PublicationNotice` 的编辑入口沿用同一回执。`refreshOnly` 只等待该次发布。后台失败仅记日志与 `meta.publicationFailures`，不显示为工作台草稿错误。磁盘与发布的具体语义见[磁盘保存与发布确认](params-write.md#磁盘保存与发布确认)；引擎重挂见[引擎装配与发布](engine-assembly.md)。

### 自动保存

文本编辑通过 `data/use-autosave.ts` 共享逻辑焦点、最新回调和输入法处理。规则身份绑定模块主语和稳定条目 key，离开时在下一帧确认焦点。组合输入跨失焦时提交最终值，身份变化取消旧回调。面板关闭早于回调时，仅提交同身份、已失焦且合成已结束的值。未加载、忙态、字段无效和远端冲突均保留草稿，等待用户恢复写资格。

文本离开规则、变量、自定义工具或指令编辑卡片时提交，参数文本离开控件时提交。模块名称输入框失焦或按 Enter 后提交，取消和 Escape 放弃改名。输入和停顿只更新草稿，选项与开关即时提交。卡内及其 portal 间移焦不提交。发送消息不等待自动保存，运行只读取已经落盘的有效值。变量的空键行留在草稿，请求省略空键，保存或读取不清理该行；具名的空字符串是有效值。参数空字符串与空数组按删除键处理，见[参数写入](params-write.md)；变量持久化见[持久变量事务](variables.md#持久变量事务)。

### 规则草稿与保存

创建应答丢失时，「核对保存结果」先读原模块。只有读回确认创建尚未写入，才显示「重试创建规则」并重用原创建请求。单条规则保存被拒后，重试只提交原先那条规则。撤回被拒的改动会清除相应的保存错误，已有版本的发布状态单独保留。跨模块互斥恢复显示目标规则 ID，成员变更写盘后即刷新启停状态。

页面不再常驻“重新读取／校验规则／保存规则／已与模块同步”一行；规则卡使用已有的失焦保存事务，提交时校验。规则文本和字段草稿在离开编辑区时提交，输入和停顿不提交；选项和开关立即提交。嵌套菜单通过局部提交通知复用同一卡的事务，启用互斥规则仍单独使用 `activateRuleId`。无效字段、未完成 JSON 与输入法组合中的文本留在草稿，不落盘也不自动删除；新建规则与空规则不因后台读取或保存失败消失。批量操作按可见卡片所属模块分别提交。失败保留对应模块草稿并显示所属模块与就地错误，只在错误时提供重试与必要的丢弃确认。恢复方式由规则编辑器的 `retryKind` / `retry()` 决定，页面不自行猜测：版本冲突后阻止旧版本再次提交，先读取；读失败仍保持读恢复。共享引用（`shared-alias`）与版本冲突同列——先让用户解除引用再重新读取，不重放那一次写。远端内容变化进入 `remote`，保留本地输入，必须显式处理冲突；普通保存失败可以重试提交，已保存但待发布只执行 `refreshOnly`。

动作与整个分支的同列表上下移动是显式提交点，适用于 then、else 与嵌套列表：最终合法值、新顺序及同模块全部合法脏编辑一次提交，其他模块草稿独立。同模块任意未完成或非法字段、仍在进行的输入法合成都拒绝移动，保留原文与原顺序且不写入；合成结束不会重放移动，须再次激活按钮。移动只清理换位子树的干净位置缓存，沿既有共享草稿与提交 owner 保存，不先失焦保存旧顺序。写拒绝保留本地新顺序，冲突须先重读；落盘成功但发布失败不回滚，重试只发布。在途新编辑继续保留为待保存草稿。

载荷使用 `expectedModuleId`、`expectedRevisions` 与 `edits[{previousId, rule, settingsChanged?}]`。正文编辑校验正文版本，改状态以及新增、删除、改名另校验 settings。普通保存和模板首写共享目标身份；模板 `createRule` 不要求现有卡片或先读取 `/rules`。跨模块 CAS 和目录拒绝见[模块主语策略](ui-bridge.md#模块主语策略)。

### 指令文件草稿

Shell + 草稿池 + 文件策略由 `data/instruction-editor.ts` 投影为指令文件卡。`instructionShellsFrom` 只认 `/bootstrap` 的文件身份段，descriptor 不提供文件壳，旧壳内正文、版本和读状态不参与回填。`fileId` 优先取 `origin`，文件卡才回退 `params.fileId`。会话切换在 `load` 前调用 `switchSession`，回填走 `ingestSnapshot`。

指令上下文优先读取存活本地 Agent 的 `session.header.cwd`；浏览尚未恢复 Agent 的历史会话时，使用官方 `sessionPersistence.stat(sessionId)` 只读 header 恢复工作区，不创建 Agent、不读取整份日志。仅会话记录或服务不存在时回退部署 cwd，读取异常按桥端点失败反馈。普通字段草稿在读取期间变化时仍回填指令上下文与文件卡，不以模块或全局参数编辑阻断文件卡显示；文件正文与策略的并发保护保持独立。

- 指令负责人事实来自 `/bootstrap` 的 `instructions.owner.officialInstructions`：`true` 仅在观察到官方装配时出现，但读协调器观察结果的通道已删除、载荷恒为 `null`（见 [ADR-0009](../adr/0009-instruction-owner-observed-only.md)），重建上报链前没有生产者。对规则来源不写 `false`——那是插件观察不到的否定事实，三态因此收敛为「观察到 / 未观察到」。文件可读与官方已装配都不能显示为该文件「已经注入」；官方未装配时插件不补建文件注入。
- 不再提供「独立指令文件来源」总开关。文件卡启停仅写独立策略 `files[fileId].enabled`，默认放行；关闭只拦截后续官方注入，不撤回历史，重新开启不强制重放。策略不可读时禁用策略编辑，保留诊断；应答成功前不乐观显示已保存。名称与开关跨预设共享，位置、顺序、晋升、受众和模型范围不属于文件卡控制项。
- bootstrap 与策略快照均读取完成后再应用，异步边界复核请求序号、会话与草稿状态。暂时离开工作区只暂停文件写资格，保留草稿与版本基线；返回并读取时，版本未变可继续保存，版本变化仍须解决冲突。
- 列表保存按钮等待真实 `Promise<boolean>` 结果；文件或预设部分失败时不显示整体成功、不以静默重载清除错误。已经成功保存的文件立即更新其基线，不因后续失败回滚或丢失确认。

文件正文离开编辑器或显式保存时提交，成功只确认请求快照。新输入仍聚焦时保留草稿，已经离开编辑器时在当前保存成功后补交最终值。失败或冲突保留草稿并提供重新读取。旧 `contextId` 写入返回 409；会话切换只暂停旧上下文的写资格。指令卡的 Agent 局部关闭为只读投影，显示控制规则并禁用共享开关，无真实 Agent 时不显示局部状态。指令路径提示的全局字段由 `paramOverrides` 无主语写入，未读回全局值或总闸关闭时禁用。编辑权限见[参数编辑器](params-editors.md)。

### 工具和变量草稿

工具编辑器以共享草稿序号接纳保存结果及发布重试。保存中不发读取，保存前在途读取由新序号失效；模板插入沿读取守卫，读取失败不以空列表覆盖。视图离开后应答更新共享基线和发布态，只停止旧视图提示。

变量卡复用同一编辑器切换 module/global；文本离开编辑区时保存，模块开关立即保存，删除仍走原变量事务。空变量名是待编辑草稿，不自动提交、删除或隐藏；命名完成后空字符串值是合法值。变量行身份不随名称输入变化，数字名称也保留编辑中的显示顺序，避免对象枚举重排或重挂导致焦点错移；值仍由原草稿拥有。范围切换先尝试提交原范围有效草稿，各范围未完成草稿继续独立保留。全局写提示影响同安装其它模块。同名覆盖来源由快照显示。普通规则的变量由用户手动建立，ST 导入才自动登记缺失裸引用为空占位。

同名引擎参数绑定同一字段和草稿键，非法数字原文与错误同步保留。显示实例拥有各自 DOM 身份。参数、变量和工具均用本地编辑 owner，协议依据见[参数架构](../architecture-params.md)。

## 导入预览与提交

工作台使用 `use-import-preview-flow` 组织文件读取、预览、确认和提交；`ImportDialog` 仅接收 props 和回调。上传暂存、资产选择及服务端安装见[资产交换](../asset-transfer.md)。

| 阶段 | 界面行为 |
|---|---|
| 读取或重新预览 | 读取时保留上次预览，换来源才清空；迟到结果不能覆盖新选择 |
| 等待确认 | 仅呈现真实候选；预览就绪且完成所有必选项时可确认，取消可聚焦；改类型或顺序组后重新预览 |
| 提交 | 确认和取消均禁用；成功后刷新事实，刷新失败可单独重试 |
| 预览过期 | 保留来源和选择，撤销旧确认，要求重新预览 |
| 其他失败 | 就地显示错误；保留文件和预览，再次确认重试，取消跳过本项 |
| 目标切换或卸载 | 结束等待并释放暂存来源，迟到应答失效，不继续提交后续项 |

同一份预览只提交一次，读取与提交期间拒绝重复操作。导入逐份排队，“跳过这份”与“结束本次导入”分开；卸载释放暂存来源，不提交后续项。同名默认另存，覆盖使用现有 ConfirmDialog。导出范围是互斥单选：完整 ZIP／仅定义 YAML；显示资源清单、缺失依赖与需明确决定的历史记忆项。弹窗复用 DialogSurface 焦点逻辑，宽预览只增加 size 修饰，不建立第二套浮层系统。
