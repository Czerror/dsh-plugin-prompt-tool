# 官方指令负责注入，插件只过滤后续消息

指令文件的发现、读取、预算、增量更新与压缩恢复由官方 `agent-instructions` 负责，插件不再建立第二条文件正文注入通道。指令文件卡保留原文件编辑、显示名和逐文件开关；开关只过滤尚未进入会话的官方消息，默认放行，不撤回历史，也不因重新开启而强制重放历史。这样保留官方生命周期，并避免修改已有会话前缀；它不承诺停止官方读取文件。

本决策替代 [ADR-0003](0003-instruction-files-independent.md) 中的插件自注入、独立来源总开关、默认关闭及位置／顺序／晋升／受众／模型范围策略；正文归用户原文件、指令策略在同一 DSH_HOME 内跨预设共享的边界不变。`instructions.yml` 只保留 `files[fileId].enabled` 与 `name`；旧行为字段读取时忽略，在下一次成功保存时清理，不把旧顶层关闭迁移为逐文件关闭。

过滤使用官方 `source.changes` 的路径与模板段落共同确认文件身份，涵盖基线、附加、更新和移除；仅删除被关闭文件的正文与对应变更元数据，其他文件及消息元数据保留。无法确认本地文件身份或可靠分段时原样放行，格式歧义给出诊断，避免猜测边界而损坏官方上下文。官方预算已经省略的内容不由插件补回，也不新增远程指令来源的管理入口。

预设级 `instructionHint` 继续默认关闭；显式开启时先做逐文件过滤，再对剩余官方消息执行现有提示转换。会话开始前关闭会阻止可识别文件进入新历史；会话中关闭只拦截后续注入，旧正文继续存在。过滤不是保密或访问控制边界。
