# 预设定义是行为配置的唯一来源

状态：单一定义源的所有权继续有效；「并由定义原子物化宿主可发现的预设」这一句已由 [ADR-0006](0006-module-config-order.md) 与 [ADR-0008](0008-module-slices-memory-assembly.md) 替代（装配改在该 Agent 自己的 scope 里按定义注册，不再依赖宿主扫描与预设物化）。以下保留原决策记录。

Prompt Tool 将每个预设的参数、模块、提示词配置、变量、模型路由和工具策略保存在预设定义中，全局 settings 只承载部署设置，并由定义原子物化宿主可发现的预设。选择这一结构而不是让 settings 或生成目录同时可写，是因为多个真相源会使 UI 状态、可移植预设与运行产物漂移。代价是修改后必须重建，换取单一验证与写入链路、确定性恢复以及可导入的预设。
