# 原生上下文、两级持久变量与官方人设继承

状态：已采纳，2026-10-11；当前源码已切换原生接口，发布验收单独记录。旧行为基线为 `dev@726a8f68`。

世界书投影工具无法完整保留规则树，ST 专用帧又把变量生命周期绑在会话和 mount 上。按用户确认，规则继续作为唯一行为定义，外部 ST 只在转换端识别；运行时使用上下文激活与模板求值，模型通过模块导入、完整规则事务、模块变量和模块记忆四类能力操作。公开旧入口直接退役，旧内部定义只能重新导入或显式转换，不增加双读、内置迁移或自动改盘。

变量只有全局与来源模块两级持久所有者，模块覆盖全局；空字符串保留，删除才回落。模板可以赋值，但先在变更集求值，一张模板只提交一个范围，并对全部实际读取范围做版本校验。选择单域原子事务而不引入跨文件日志，意味着双域赋值整卡拒绝、跨卡不承诺全有全无。成功提交的执行凭据独立于 mount，发布失败只重试发布；持久化不等于承诺任意崩溃后的跨进程 exactly-once。

人设仍由各模块的 persona.main/subagent 保存完整正文。按后续确认，主会话与子代理各自单选一个模块来源，默认官方；config.yml.personaSources 只保存 main/subagent 的模块 ID，不复制正文，选择也不启用该模块的规则。运行时只读所选受众字段，取代此前多启用模块逐字段合并/重复字段冲突的方案。所选字段省略仍继承官方，空文本与 false 保持显式含义。

人设不参与规则排序，rules/_settings.yml 可保存由 module.yml 恢复的校验投影。单选来源仍需预检人设与同受众规则的 complete 冲突；人设与规则在同一次装配里挂载，失败保留上次有效配装，不以事后恢复结果替代装配期决定。接入验收包括真实 Loader、共享预设、子代理 setup 与卸载生命周期。

后续启动事故复核取消了独立人设早入口和对 system-prompt 的 Loader 等待：可选插件不能改变官方核心启动依赖，也不能改为让核心依赖插件服务。用户选择会话期官方 API 组合：继承人设在原 Agent scope 覆盖，自有官方 Persona 在空闲维护窗口接管准确注册，新建/恢复会话只在 setup 窗口捕获目标声明；未知直接注册保持原状并报告。维护锁覆盖异步配装提交/回滚，不改变历史或共享预设，不采用派生 scope 路由、非空会话重配或私有层修改。

同日再修订：上述「接管官方 fiber + 空闲维护窗口」整体退场，人设装载并入运行时配装通道。装配在**每个 Agent 自己的 scope** 注册同名 `deployment:persona-prefix/suffix`，靠 scope 链遮蔽（近者胜）替换全局部署人设与预设 persona 行，因此不需要接管任何人的 fiber；只有 Agent scope 同层已被注册的声明才需要先撤后挂，撤销凭据来自 AgentSetup 窗口内的捕获。用户明确要求插件人设**优先于其他来源**，并接受两项降级：窗口之外出现的同层官方 persona 行不再接管（报告并保留旧装配），以及取消「Agent 忙碌时拒绝保存、等空闲重试」——人设随装配立即重挂。

普通规则只引用手动建立的变量，不自动扫描登记；ST 导入负责把缺失裸引用登记为空占位。空串属于显式值，不能与删除或未声明混同。工具更新变量与模板赋值共用同一存储 owner。

2026-11-02 修订（Issue 35）：按用户确认新增来源模块＋真实会话隔离的 session 持久域，裸引用优先级变为 session→module→global；module.get/global.get 保持原范围，空串及删除语义不变。会话数据使用官方 storageDomain，不另建文件存储引擎；session setter 由异步规则和模型工具等待持久化，人设同步出口仅读取该域。通用模板、条件及 SELF 共用既有求值链，runtime 是显式只读权威事实域，不存第二份账本计数。SELF 只读；close、投递确认与恢复额度仍归原业务事务。

会话短状态统一为 soul.mark；旧状态文件首读不迁移、首次合法写一次提交到官方域且保留原件。宿主维护逐键时间戳，所有写入口统一限长和CAS。会话域不自动随 fork 或日志导出，官方持久化开始后取消不代表回滚。变量总闸覆盖新求值域；工作台与bridge仍只编辑模块/全局，不增加指定他人会话入口。此修订只替代本ADR的“两级所有者、裸引用覆盖顺序”限制，其余原生上下文、人设与单域提交决定保持。

2026-11-02 修订（Issue 37）：人设改为普通规则中的 persona 动作，取代前文的顶层 persona.main/subagent、config.yml.personaSources 单选、独立正文保存与 settings 投影。正文、资格、排序和生命周期统一归 ruleRuntime；所有启用模块的命中动作按既有规则序与动作声明序分别拼接 prefix/suffix，主子按真实 Agent 分别聚合。字段全省略才继承，显式空串阻止该字段继承但不清除其它片段；complete/includeRuntimeContext 显式值冲突拒绝整组并保旧。全部失配或必要事实不可用撤回本插件人设、恢复官方；配置、求值或注册错误报告并保留最后有效贡献。旧格式在读取根拒绝，由用户手工重建规则并移除旧键，不自动迁移、不双读、不改用户文件。

动态候选在原官方 assemble 前准备并提交，因为官方在 waterfall 前保存 complete 副本。同 Agent 的准备与原装配串行、每次固定候选；不同 Agent 可并发，全局刷新事务等待各 Agent 锁。官方继承与 AgentSetup 同层捕获保留为 adapter：暂撤的原声明在回退/卸载时恢复，但原 owner 释放后不得复活。includeRuntimeContext:true 只撤本插件抑制，祖先 scope 的抑制保持。自定义片段沿各自规则来源读取变量与 runtime，继承官方正文不重新求模板；同步人设 session setter 仍拒绝。此修订替代本 ADR 先前的人设单选与释放降级决定，保留官方服务启动依赖、scope 隔离和单域变量事务约束。
