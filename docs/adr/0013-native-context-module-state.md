# 原生上下文、两级持久变量与官方人设继承

状态：已采纳，2026-10-11；当前源码已切换原生接口，发布验收单独记录。旧行为基线为 `dev@726a8f68`。

世界书投影工具无法完整保留规则树，ST 专用帧又把变量生命周期绑在会话和 mount 上。按用户确认，规则继续作为唯一行为定义，外部 ST 只在转换端识别；运行时使用上下文激活与模板求值，模型通过模块导入、完整规则事务、模块变量和模块记忆四类能力操作。公开旧入口直接退役，旧内部定义只能重新导入或显式转换，不增加双读、内置迁移或自动改盘。

变量只有全局与来源模块两级持久所有者，模块覆盖全局；空字符串保留，删除才回落。模板可以赋值，但先在变更集求值，一张模板只提交一个范围，并对全部实际读取范围做版本校验。选择单域原子事务而不引入跨文件日志，意味着双域赋值整卡拒绝、跨卡不承诺全有全无。成功提交的执行凭据独立于 mount，发布失败只重试发布；持久化不等于承诺任意崩溃后的跨进程 exactly-once。

人设仍由各模块的 persona.main/subagent 保存完整正文。按后续确认，主会话与子代理各自单选一个模块来源，默认官方；config.yml.personaSources 只保存 main/subagent 的模块 ID，不复制正文，选择也不启用该模块的规则。运行时只读所选受众字段，取代此前多启用模块逐字段合并/重复字段冲突的方案。所选字段省略仍继承官方，空文本与 false 保持显式含义。

人设不参与规则排序，rules/_settings.yml 可保存由 module.yml 恢复的校验投影。单选来源仍需预检有效官方人设与启用规则的 complete 冲突；完整 prepare/commit/rollback 同时覆盖规则与人设，失败保留上次有效配装。正文与 complete 在官方声明注册或首次装配前共同确定，不以事后恢复结果替代。接入验收包括真实 Loader、共享预设、子代理 setup 与卸载生命周期。

普通规则只引用手动建立的变量，不自动扫描登记；ST 导入负责把缺失裸引用登记为空占位。空串属于显式值，不能与删除或未声明混同。工具更新变量与模板赋值共用同一存储 owner。

本决策取代 [ADR-0008](0008-module-slices-memory-assembly.md) 的公开旧名兼容和世界书 note 记忆入口，并替代此前文档中的会话变量及 ST local/global 所有权。继续保留该 ADR 的完整定义、切片恢复、提交后发布失败语义；[ADR-0006](0006-module-config-order.md) 的配置排序、[ADR-0007](0007-unified-condition-action-rules.md) 的规则与显式互斥、[ADR-0010](0010-two-history-views.md) 的历史视图分工均不变。

字段和事务所有权见 [后端框架](../architecture-params.md#原生格式与持久状态)，外部字段映射见 [SillyTavern 导入](../SillyTavern.md#原生转换映射)，工具与执行边界见 [引擎复用](../engine-reuse.md#原生运行与工具面)。这些文档解释权威 schema 与契约，不增加第二套校验定义。
