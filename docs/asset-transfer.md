# 资产导入与模块导出

资产语义由 host 识别；页面负责选择来源、显示预览和提交用户决定。module.yml 是完整持久定义，rules/ 是经校验的运行切片。角色卡只是导入来源，落为普通 modules/<id>/；模块记忆和工作区指令正文各有独立所有者。

## 输入与入口

模块页支持文件夹、ZIP、原生 JSON/YAML 定义，以及 ST 预设、角色卡和世界书来源。PNG/JSON 角色卡沿同一预览与安装链创建普通模块，没有独立角色库、character- 前缀目录或新角色专属登记。

单文件上传走 `/asset-upload`，只写当前 bridge 拥有的暂存来源；来源句柄有效期 15 分钟，每个 bridge 最多保留 4 份。取消、释放、卸载会回收来源；重启只回收带本插件标记且已过期的来源。旧 `/characters-import-stream` 返回升级提示，不再直接入库。

文件夹使用显式 `base64` 字节载荷。JSON bridge 保持 32 MiB 上限，原始来源和 ZIP 解压总量上限为 64 MiB、最多 2048 个条目；较大的文件夹请先压缩为 ZIP。路径、编码、字节上限与 PNG chunk／解压限制均在宿主复检。

文件夹和 ZIP 只剥离一层统一外壳。顶层唯一原生定义确定后，其余文件作为附件，不因附件包含 ST 顺序表而改变转换。无原生定义的多份 ST 来源按显式输入顺序合并，转换报告复用同一份 ID 映射。未知、矛盾或多定义输入拒绝，不能成功生成空配置。

## 预览与提交

预览显示来源类型、目标 ID／名称、文件数与字节、配置数、转换诊断及类型／顺序组候选。原生文件同样有资源摘要。默认同名另存，用户选择覆盖后须明确确认；改变来源、目标、名称、类型、组或覆盖模式都会使旧确认失效。

来源摘要和预览版本由服务端计算，绑定内容、选择与当前目标版本。提交必须回传两者；读取失败不能当成目标不存在。过期返回冲突，UI 保留来源并提供重新预览。

模块安装先在同文件系统暂存完整候选，使用 writeModule 的 sourceDir + stageOnly 完成定义、工具、模板和组合校验，并从完整定义重建 rules/。候选所在目录使用合法目标 id，确认目标版本仍一致后交换目录。候选失败不修改旧目标或兄弟模块；占用导致交换失败时保留原目标，恢复失败保留备份位置。普通重建只原地恢复切片，不复用整目录交换。

来源包可以附带 rules/，但预览、导入与运行都以完整 module.yml 为提交依据；不一致的切片在隔离候选中重建。预览保持只读；导出读取已提交定义，不将失配切片反向写入。

安装成功与列表刷新分开报告，刷新失败不自动重复安装。导入不自动切换当前编辑模块；用户可在结果页显式切换。

角色来源覆盖同一模块时保留 memory.md、未知用户资产与未替换头像；普通模块包覆盖仍以用户确认的完整候选为准。记忆只由 world_book_read_memory 按需读取，不因导入或更新自动注入。旧 .characters 库只作迁移检测与可见诊断，不作为新的写入目标。

## 导出、复制与分享边界

“完整 ZIP”包含权威定义、预设正文、图片、自有组合和本地模块，附 `prompt-tool-package.json` 的格式版本、兼容要求与文件摘要。导入检查清单与实际条目一致；ZIP 的上跳、绝对路径、链接、特殊文件、大小写／规范化冲突、加密、损坏及解压超限均拒绝。

共享引擎由插件包提供，不从来源机器复制。旧 configs/、rules.yml、agent.cordis.yml、custom-tools/、subagent-tools/ 不再分发；规则切片可从完整定义重建。memory.md 默认不随分享导出，技能库和工作区指令／策略也不属于模块交换包。根 agents.md 是已有模块内容资产，与工作区指令文件分开。

> **导入不安装引擎**：完整模块包只含模块自身（定义、正文、附件、自有组合与本地模块）；组合里的共享引擎引用是插件包说明符，导入方由**自己安装的插件**提供引擎。包内若仍带 `engine/` 目录，导入后不再被使用——引擎版本只随插件更新。

“仅定义 YAML”不携带附件，界面说明遗漏数量。完整导出检查显式本地模块与模板引用；缺失或根外资源阻止完整下载，定义模式仍说明限制。静态检查不能证明任意用户模块动态构造的路径完整，用户模块的运行前提仍需自行提供。

历史模块可能带自动同步的记忆规则及 meta.characterMemories 证明。分享出口继续在副本中排除可核验的历史自动记忆，不修改原模块；普通同名规则保留，无法确认的历史条目须明确选择。新记忆写入不再生成该类规则或登记，入站来源的生成证明不可信。

模块复制保留本地行为与素材，不套用分享时的记忆过滤；新目录与完整定义同步新身份，规则切片重新生成。Web 和 CLI 共用当前 `.prompt-tool` 定位规则，不优先读取旧 `presets` 根。

导出走工作台与插件公开 API（`exportPresetPackage` / `expandPresetSource`；模块命名的
`exportModulePackage` / `expandModuleSource` 是同一实现）：ZIP、仅定义 YAML 与文件夹三种出口
共用同一资源清单和分享规则，目标省略时下载为 `<id>.zip`，已存在目标拒绝覆盖。

## 模块归属

| 文件 | 责任 |
|---|---|
| `shared/asset-transfer.ts`、`bridge-contract.ts` | 字节、选择、摘要与响应契约 |
| `host/import-source.ts`、`character-png.ts` | 内容判别、转换、来源报告、受限 PNG 解码 |
| `host/asset-sources.ts`、`asset-archive.ts` | 生命周期暂存、ZIP 载体与边界校验 |
| `host/module-package.ts` | 预览、严格候选、安装与导出 |
| `host/module-install.ts`、`manifest.ts`、`write-module.ts`、`module-storage.ts` | 合法身份、根归属、复制、候选校验、完整定义提交与切片恢复 |
| `host/characters.ts` | 普通模块合并／移除、模块记忆与历史分享证明兼容 |
| `client/data/use-import-preview-flow.ts`、`ui/ImportDialog.tsx` | 读取到结果的统一生命周期与共享呈现 |

安全与文件行为以 Node 回归验证；真实浏览器覆盖文件输入、确认、过期、批次取消、错误和键盘。所有测试使用隔离 cwd 和合成 DSH_HOME，不操作运行中服务。
