# 资产导入与预设导出

资产语义由 host 识别；页面负责选择来源、显示预览和提交用户决定。`preset.yml` 仍是预设行为的唯一来源，角色卡库、角色记忆和指令文件各自独立。

## 输入与入口

预设页支持文件夹、ZIP、原生 JSON/YAML 预设，以及 ST JSON/YAML 预设、角色卡和世界书 JSON；PNG 角色卡可以转换为预设。角色页接收 PNG、JSON、YAML，批次按文件逐张确认。原生 `converted.yml` 支持自包含 `text`、`texts` 与合法控制配置；角色库拒绝文件引用，带附件的内容使用完整预设入口。

单文件上传走 `/asset-upload`，只写当前 bridge 拥有的暂存来源；来源句柄有效期 15 分钟，每个 bridge 最多保留 4 份。取消、释放、卸载会回收来源；重启只回收带本插件标记且已过期的来源。旧 `/characters-import-stream` 返回升级提示，不再直接入库。

文件夹使用显式 `base64` 字节载荷。JSON bridge 保持 32 MiB 上限，原始来源和 ZIP 解压总量上限为 64 MiB、最多 2048 个条目；较大的文件夹请先压缩为 ZIP。路径、编码、字节上限与 PNG chunk／解压限制均在宿主复检。

文件夹和 ZIP 只剥离一层统一外壳。顶层唯一原生定义确定后，其余文件作为附件，不因附件包含 ST 顺序表而改变转换。无原生定义的多份 ST 来源按显式输入顺序合并，转换报告复用同一份 ID 映射。未知、矛盾或多定义输入拒绝，不能成功生成空配置。

## 预览与提交

预览显示来源类型、目标 ID／名称、文件数与字节、配置数、转换诊断及类型／顺序组候选。原生文件同样有资源摘要。默认同名另存，用户选择覆盖后须明确确认；改变来源、目标、名称、类型、组或覆盖模式都会使旧确认失效。

来源摘要和预览版本由服务端计算，绑定内容、选择与当前目标版本。提交必须回传两者；读取失败不能当成目标不存在。过期返回冲突，UI 保留来源并提供重新预览。

预设安装先在同文件系统暂存完整候选，验证配置、工具、模板文件及组合，再调用 writer 的 `sourceDir + materializeOnly` 入口物化；确认目标版本仍一致后交换目录。候选渲染不修改兄弟预设或旧目标，也不物化共享引擎（引擎由插件包提供）。Windows 占用时安装失败并保留旧目标，不进入普通重建的原地覆盖回退。恢复失败保留原目录备份及其位置。

安装成功与列表刷新分开报告，刷新失败不自动重复安装。导入不自动切换当前预设；用户可在结果页显式切换。

角色更新在自身事务中保留 `memory.md`、未知用户文件和未替换头像；原生片段的实际应用数量按新增配置计算。角色库不把多个来源合并成一张卡。

## 导出、复制与分享边界

“完整 ZIP”包含权威定义、预设正文、图片、自有组合和本地模块，附 `prompt-tool-package.json` 的格式版本、兼容要求与文件摘要。导入检查清单与实际条目一致；ZIP 的上跳、绝对路径、链接、特殊文件、大小写／规范化冲突、加密、损坏及解压超限均拒绝。

共享引擎由**插件包**提供，不随预设分发、也不从来源机器复制：组合行的引擎引用是包名说明符 `dsh-plugin-prompt-tool/engine/<module>.mjs`，预设根下不再物化 `.engine/`。运行期生成的配置目录、缓存、角色记忆文件、角色库、技能库和工作区指令／策略不随包分发。根 `agents.md` 是既有预设内容资产，与工作区指令文件分开管理。

“仅定义 YAML”不携带附件，界面说明遗漏数量。完整导出检查显式本地模块与模板引用；缺失或根外资源阻止完整下载，定义模式仍说明限制。静态检查不能证明任意用户模块动态构造的路径完整，用户模块的运行前提仍需自行提供。

角色记忆可能已有自动同步的提示词副本。宿主在 `meta.characterMemories` 记录生成项身份和摘要，两种分享出口都在导出副本中排除可核验的自动记忆，不改原预设。普通同名配置保留；无法确认的历史条目必须明确选择保留或排除。入站来源中的生成证明不可信，会被去除。

预设复制保留本地行为与角色关联，不套用分享时的记忆过滤；新目录、定义和受管引用同步新身份。Web 和 CLI 共用当前 `.agent-presets` 定位规则，不优先读取旧 `presets` 根。

CLI 在构建后使用：

```powershell
node scripts/export-preset.mjs pt-standard output.zip
node scripts/export-preset.mjs pt-standard output.yml
node scripts/export-preset.mjs pt-standard new-output-directory
```

目标省略时下载为 `<id>.zip`；已存在目标拒绝覆盖。文件夹出口沿用同一资源清单和分享规则。

## 模块归属

| 文件 | 责任 |
|---|---|
| `shared/asset-transfer.ts`、`bridge-contract.ts` | 字节、选择、摘要与响应契约 |
| `host/import-source.ts`、`character-png.ts` | 内容判别、转换、来源报告、受限 PNG 解码 |
| `host/asset-sources.ts`、`asset-archive.ts` | 生命周期暂存、ZIP 载体与边界校验 |
| `host/preset-package.ts` | 预览、严格候选、安装与导出 |
| `host/preset-install.ts`、`manifest.ts`、`write-preset.ts` | 合法身份、根归属、复制、候选物化与引擎引用改写 |
| `host/characters.ts` | 角色库更新、应用／移除及记忆来源证明 |
| `client/data/use-import-preview-flow.ts`、`ui/ImportDialog.tsx` | 读取到结果的统一生命周期与共享呈现 |

安全与文件行为以 Node 回归验证；真实浏览器覆盖文件输入、确认、过期、批次取消、错误和键盘。所有测试使用隔离 cwd 和合成 DSH_HOME，不操作运行中服务。
